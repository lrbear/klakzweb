# KLAKZHUB

A dark-themed resource library starter built with Next.js, React, TypeScript and Tailwind CSS.

## Run locally

1. Install [Node.js LTS](https://nodejs.org/).
2. Open a terminal in the folder containing `package.json`.
3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open http://localhost:3000.

## GitHub upload

Upload the **contents** of this folder to the root of your GitHub repository. Do not upload the ZIP as a single file. `package.json` must be at the repository root.

## Deploy to Vercel

1. Push the repository to GitHub.
2. Import the repository at https://vercel.com/new.
3. Keep the framework preset as Next.js and deploy.

## Important

This is a starter/demo project. The `/admin` page is a visual demo only: it has no login, database, or persistent storage. Do not use it as a public admin system until authentication, authorization, validation, and a database are implemented.
